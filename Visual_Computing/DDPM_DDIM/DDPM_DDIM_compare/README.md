**DDPM vs DDIM 샘플링 속도·품질 비교**

동일한 학습 모델을 사용하여 기존 DDPM 샘플러와 DDIM(Denoising Diffusion Implicit Models) 샘플러의 **샘플링 스텝 수에 따른 속도 및 품질 차이**를 비교한 프로젝트입니다.



**주요 내용**

- **학습**: DDPM 폴더와 동일한 포켓몬 스프라이트 데이터(약 800장), 컬러 64×64, 500 스텝으로 모델 단 하나만 학습.
- **DDIM 샘플러 구현**: non-Markovian forward 과정으로 재정의하여 부분 시점만 선택해 빠르게 생성. `eta=0`(결정론적)과 `eta=1`(확률적) 모드 모두 구현.
- **비교 실험**:
  | 샘플러 | 스텝 수 | 생성 시간(16장) |
  |--------|---------|----------------|
  | DDPM   | 500     | ~3.16s         |
  | DDIM   | 100     | ~0.60s         |
  | DDIM   | 50      | ~0.33s         |
  | DDIM   | 20      | ~0.14s         |
  | DDIM   | 10      | ~0.17s         |
- **결론**: DDIM 50 스텝에서 DDPM 대비 약 10× 빠른 속도로 유사한 품질의 이미지 생성 가능. eta=0(결정론적)과 eta=1(확률적) 간 시각적 차이도 확인.
